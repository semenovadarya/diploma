# Прогнозирование волатильности индекса Московской биржи (IMOEX) моделями ARCH/GARCH

Репозиторий к выпускной квалификационной работе **«Применение моделей ARCH/GARCH для прогнозирования волатильности биржевых временных рядов»**.

## О проекте

Эмпирическое сравнение подходов к прогнозированию условной волатильности индекса Московской биржи (IMOEX): простая историческая оценка, ARCH(5), GARCH(1,1) и GJR-GARCH(1,1,1) с t-распределением Стьюдента. Проверяется, обеспечивает ли усложнение модели статистически и практически значимый прирост точности прогноза.

## Содержание репозитория

- `IMOEX_analysis.ipynb` — полный анализ: загрузка данных, расчёт логарифмических доходностей, диагностика ряда, построение модели условного среднего, оценивание моделей волатильности, вневыборочное сравнение прогнозов и ретроспективная проверка Value-at-Risk.

## Данные

- Индекс Московской биржи (IMOEX), дневные значения закрытия.
- Период: 05.01.2015 – 30.04.2026 (2846 наблюдений).
- Логарифмические доходности; разбиение на обучающую (2253) и тестовую (592) выборки.

## Методология

| Этап | Инструмент |
|---|---|
| Диагностика ряда | ADF, тест Льюнга–Бокса, тест Жарке–Бера, тест на ARCH-эффект |
| Условное среднее | ARMA(2,3) |
| Условная волатильность | ARCH(5), GARCH(1,1), GJR-GARCH-t |
| Качество прогноза | AIC, BIC, MSE, MAE, QLIKE, тест Диболда–Мариано |
| Практическая проверка | Value-at-Risk (95% и 99%), тест Купика |

## Основные результаты

- Лучшая модель — **GJR-GARCH-t** (по информационным критериям AIC/BIC и всем вневыборочным метрикам).
- Модели семейства GARCH значимо точнее простой исторической оценки; преимущество GJR-GARCH-t над GARCH(1,1) статистически не подтверждено (тест Диболда–Мариано, p = 0.875).
- Ретроспективная проверка Value-at-Risk: пройдена на уровне 99%, не пройдена на уровне 95%.
